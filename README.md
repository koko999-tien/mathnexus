# MathNexus

Không gian học toán — bài học ngắn, tủ sách, công thức có lời giải thích, luyện tập, đồ thị hàm số và công cụ. Chạy tốt trên **laptop** và **điện thoại**.

Repo này **tách biệt** với [LegalOS](https://github.com/koko999-tien/legaios).

## Xem trên trình duyệt

File `index.html` là trang web đầy đủ, không cần cài đặt.

### GitHub Pages

1. Vào **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder `/ (root)`
4. Mở: **https://koko999-tien.github.io/mathnexus/**

Hoặc bật **GitHub Actions** — workflow `.github/workflows/pages.yml` sẽ tự triển khai.

## Có gì bên trong

- Thư viện bài học (THCS → đại học)
- Tủ sách chọn lọc
- Tư duy & phản ví dụ
- Luyện tập theo chuyên đề
- Đồ thị hàm số
- Công cụ: UCLN/BCNN, bậc hai, tổ hợp, số phức, nguyên tố
- Soạn & hiểu công thức
- Trợ lý AI trên máy (trả lời từ thư viện trong app)
- Sổ tay + tiến độ lưu trên trình duyệt (`localStorage`)

## Dữ liệu

Tiến độ học (bài đã đọc, câu hỏi, sổ tay) nằm trên máy bạn. Nút **Tải tiến độ JSON** ở trang Tiến độ để xuất dữ liệu.
