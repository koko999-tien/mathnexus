# MathNexus

Không gian học toán — bài học ngắn, tủ sách, công thức có lời giải thích, luyện tập, đồ thị hàm số và công cụ. React + TypeScript + Tailwind CSS + KaTeX.

## Xem trên trình duyệt

**https://koko999-tien.github.io/mathnexus/**

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output: `dist/`

## Tech Stack

- React 18 + TypeScript
- Vite (build tool)
- Tailwind CSS (responsive, dark mode)
- KaTeX (công thức toán)
- React Router v6 (SPA routing)
- PWA-ready

## Features

- 📚 28 bài học (THCS → Đại học)
- 📖 16 tủ sách chọn lọc
- 🔢 20 công thức (KaTeX rendering)
- 🧪 Luyện tập theo chuyên đề
- 📊 Đồ thị hàm số (Canvas)
- 🧮 Công cụ: UCLN, bậc hai, tổ hợp, số phức
- 🤖 Trợ lý AI trên máy
- 📝 Sổ tay + tiến độ (localStorage)
- 🌙 Dark mode
- 📱 Responsive mobile-first
- ⚡ PWA offline-ready

## Deploy

Tự deploy lên GitHub Pages khi push vào `main` qua GitHub Actions.
